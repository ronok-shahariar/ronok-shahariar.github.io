High-throughput data plane software, zero-copy kernel bypass pipelines using DPDK (Data Plane Development Kit), SDR (Software-Defined Radio), and low-latency systems infrastructure.

Production Context & Engineering Scope

This multi-gigabit data acquisition (DAQ) and record/playback platform was engineered for a US-based telecommunications enterprise to address deterministic packet capture demands during wideband satellite telemetry reception. Under high-rate ingress, traditional Linux kernel networking introduces frame loss through interrupt servicing, scheduler context switching, and copy operations.

Core Responsibilities & Contributions:

  • System Architecture: Designed the user-space data plane topology, HugePage memory layouts, and lockless ring hierarchies.
  • Inter-Interface Bridging: Implemented IPC synchronization using POSIX shared memory with sequence locks, gRPC telemetry daemons, and a VISA/SCPI automation layer.
  • Line-Rate Verification: Built automated loopback validation pipelines to bench-test packet stability and verify zero-loss transmission under sustained load.

Subsystem Breakdown:

  1. Part 1: RF Signal Capture & Ingress (Flex Compute FPGA) – Multi-channel digital RF framing and multi-gigabit streaming.
  2. Part 2: Dual Triggering Subsystem & Test Automation – Hardware TTL synchronization and VISA/SCPI instrument bridging.
  3. Part 3: High-Speed Core Data Plane (Primary & Secondary DPDK) – User-space PMD polling, HugePages, and seqlock-based shared memory IPC.
  4. Part 4: Real-Time Observability & Monitoring – Local UNIX domain socket counters, gRPC streaming, and live Prometheus/Grafana dashboards.
  5. Part 5: Operator Interfaces, Intel VTune Profiling & Line-Rate Benchmarks – Interactive CLI/GUI control tools, Intel VTune CPU performance profiling, and zero-drop loopback verification.
