### Undergraduate Thesis

<a href="/publication/2023-wireless-secrecy-simo" target="_blank" rel="noopener noreferrer"><strong>Analyzing Secrecy Performance in Wireless Communication Networks with Randomly Distributed Eavesdroppers</strong></a>

**Supervisor:** Milton Kumar Kundu  
Assistant Professor, Department of ECE, RUET

The research studied the security performance of wireless communication networks in the presence of randomly located eavesdroppers. The work included secrecy outage probability, achievable secrecy rates, wireless fading models, stochastic geometry, and <a href="https://en.wikipedia.org/wiki/Poisson_point_process" target="_blank" rel="noopener noreferrer">Poisson Point Process (PPP)</a> based network modeling.

Department of ECE, RUET

The review explored wearable and non-invasive sensing technologies that can support the early detection and continuous monitoring of lymphedema. # Selected Hardware & Research Projects

## 3-Stage Pipelined RISC-V Core & Automated Cocotb Regression Suite

**Siliconova VLSI Track**  
**Technologies:** Verilog, Cocotb, Verilator, GTKWave

- Refactored a single-cycle <a href="https://github.com/YosysHQ/picorv32" target="_blank" rel="noopener noreferrer">PicoRV32</a> processor into a 3-stage pipelined architecture.

- Divided the processor datapath into:
  - Instruction Fetch (IF)
  - Instruction Decode / Execute (ID/EX)
  - Memory Access / Writeback (MEM/WB)

- Implemented a Hazard Detection Unit to handle load-use dependencies.

- Added combinational data forwarding to reduce unnecessary pipeline stalls caused by Read-After-Write (RAW) dependencies.

- Implemented branch-flushing logic to remove incorrectly fetched instructions after a branch decision.

- Developed cycle-accurate Python testbenches using <a href="https://www.cocotb.org/" target="_blank" rel="noopener noreferrer">Cocotb</a>.

- Used <a href="https://verilator.org/" target="_blank" rel="noopener noreferrer">Verilator</a> for simulation and GTKWave for waveform analysis.

- Automated regression testing using Makefiles.

## Digital Logic Blocks & Verification Suite

**Academic & Open-Source Track**  
**Technologies:** Verilog, Cocotb, Icarus Verilog

- Designed a configurable synchronous First-In, First-Out (FIFO) buffer in Verilog.

- Implemented full, empty, almost-full, and almost-empty status indicators.

- Tested simultaneous read and write operations using Cocotb.

- Verified FIFO pointer behavior, overflow and underflow handling, and data accuracy.

- Designed Moore and Mealy Finite State Machine (FSM) controllers for digital communication and control applications.
